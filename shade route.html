About ShadeRoute

ShadeRoute is a proposed AI-assisted urban navigation platform designed to help people discover shaded walking routes, identify shaded parking areas and understand urban shade distribution.


Technology Stack

HTML, CSS and JavaScript — website interface

Leaflet and OpenStreetMap — interactive map

OSRM — demonstration road routing

Canvas API — basic image brightness analysis

Future integration — Python, OpenCV and trained AI models


AI Risks and Limitations

Incorrect shade estimates, outdated map information, image lighting differences, privacy concerns and inaccurate predictions can affect results.

ShadeRoute should be treated as a decision-support prototype, not a replacement for verified navigation or environmental data.
